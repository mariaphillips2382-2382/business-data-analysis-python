# Business Data Quality Analysis with Python

## Overview

This project demonstrates how Python can be used to identify common data-quality issues in a business dataset.

The project analyzes customer records and identifies missing values and duplicate customer IDs.

## Business Objective

Data quality issues can affect reporting, customer communications, operational processes, and business decision-making.

The objective of this project is to create a simple, repeatable process for identifying common data-quality problems.

## Analysis Performed

The Python script performs the following checks:

- Counts the total number of customer records
- Identifies missing values
- Identifies duplicate customer IDs
- Produces a business data-quality report
